# Raw / Processed Expression Data

The large NASA expression file is not stored in this GitHub repository.

To reproduce the analysis, download:

`GLDS-720_rna_seq_Normalized_Counts_GLbulkRNAseq.csv`

from NASA OSD-871 / GeneLab and place it inside:

`01_RAW_DATA/`

This file contains NASA-processed normalized expression values used for descriptive marker analysis and figure generation.

It is not raw RNA-seq count data and was not used for an independent DESeq2 analysis.
